# bokusai-topics

スマホアプリ「ぼくさい」の「今週のお題」の予定表です。アプリは `schedule.json` を読み込んで表示します。

## 書き方

`topics` に、開始日（`start`）と各言語のお題（`title`）を並べます。

```json
{ "start": "2026-10-05", "title": { "ja": "何度でも読み返せる漫画", "en": "Manga you can reread forever" } }
```

- 開始日が今日以前で、いちばん新しいお題が表示されます（日付は利用者の端末の日付で判定）。
- 日付は `YYYY-MM-DD` 形式で書きます。
- 対応していない言語の利用者には英語、英語も無ければ日本語のお題が出ます。
- この保管庫は公開です。先の週のお題を書くと誰でも見られるので、書くのは数週間先までにしてください。
- 変更がアプリに届くまで、最大で数分かかります。
